SEO для Hearthstone-сайтов: мета-теги, предпросмотр сниппета, анализ текста, карта сайта, разметка, колоды.

== Description ==

Частный плагин для hs-manacost.ru и kolodahearthstone.com. Заменяет AIOSEO и вывод `svl-seo.php`:

* заголовок, описание, canonical, robots, Open Graph и Twitter из одного места;
* панель в статье и рубрике: сниппет, анализ, оценка, соцсети, содержание;
* XML-карта сайта, robots.txt, коды подтверждения, IndexNow;
* разметка JSON-LD, хлебные крошки, SEO авторов;
* граф ссылок, аудит, массовый редактор, короткие ссылки, блоки перехода на площадки;
* колоды Hearthstone: шаблоны, правило каноникала для версий одной колоды;
* импорт из AIOSEO, svl-seo и Rank Math (исходные данные не меняются).

Подробная памятка администратору — `docs/ADMIN.md` в репозитории проекта.

== Installation ==

1. Сделайте резервную копию базы и файлов сайта.
2. «Плагины» → «Добавить новый» → «Загрузить плагин», выберите `indexpilot-1.0.0-rc1.zip`, установите и активируйте.
   Или распакуйте архив в `wp-content/plugins/indexpilot/` и активируйте плагин в списке.
3. «IndexPilot» → «Импорт»: сначала «Показать, что будет перенесено», затем настоящий импорт из AIOSEO.
4. Отключите вывод AIOSEO и модуль `svl-seo` (пока они включены, IndexPilot теги не выводит, чтобы не задвоить их).
5. Сбросьте кеш страниц (WP Rocket, Cloudflare, Redis) и отправьте карту сайта `/sitemap_index.xml` в Search Console и Вебмастер.

Обновление: замените файлы плагина новой версией. Таблицы плагина обновятся сами при первой загрузке сайта, настройки и мета записей сохраняются.

== Rollback ==

Откат занимает около пяти минут:

1. Деактивируйте IndexPilot.
2. Включите вывод AIOSEO (импорт его данные не трогает).
3. Сбросьте кеш страниц (WP Rocket, Cloudflare, Redis).

Данные IndexPilot остаются в базе (мета `_indexpilot_*`, опция `indexpilot_settings`, таблицы `{prefix}indexpilot_*`), повторная активация возвращает всё как было.

== Uninstall ==

Удаление плагина стирает его данные только если в «IndexPilot» → «Настройки» отмечено «Удаление плагина: при удалении плагина стереть все его данные и настройки». Без этой настройки мета, настройки и таблицы остаются в базе.
