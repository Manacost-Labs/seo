# IndexPilot: памятка администратору

Памятка для того, кто ставит плагин на сайт и следит за ним. Редактору статей нужна другая — `docs/EDITORS.md`.

Всё меню плагина — пункт **IndexPilot** в левой колонке админки:

| Пункт | Что там |
|---|---|
| Обзор | До пяти главных дел по сайту и ссылки на отчёты |
| Контент → Массовый редактор | Заголовки и описания многих записей и рубрик в одной таблице |
| Контент → Аудит | Дубли заголовков и описаний, пустые описания, короткие тексты, похожие тексты |
| Контент → Ссылки | Записи без входящих ссылок, глубина от главной, ссылки на удалённые и перенаправленные адреса |
| Контент → Картинки | Картинки без описания, тяжёлые файлы |
| Контент → После патча | Гайды и колоды, не обновлённые после текущего патча |
| Переходы → Переходы | Сколько читателей ушло из статей на Boosty, Hearthpulse, ВКонтакте, Telegram |
| Переходы → Площадки и блоки | Адреса площадок и правила блоков перехода в статьях |
| Техника → Редиректы | Цепочки перенаправлений и записи под редиректом (данные плагина Redirection) |
| Техника → Поисковики | Карта сайта, файл ключа IndexNow, журнал отправок, ссылки на кабинеты поисковиков |
| Техника → Короткие ссылки | Ссылки вида `/go/…` и их статистика |
| Настройки | Всё, что включается галочками (ниже) |
| Импорт | Перенос данных из AIOSEO, svl-seo и Rank Math |

## 1. Перед установкой

1. Сделайте резервную копию базы и файлов сайта (как обычно делаете перед обновлением).
2. Сохраните «снимок до»: с любого компьютера с PHP из папки проекта:
   ```
   php tools/compare-head.php sample https://hs-manacost.ru sample.txt
   php tools/compare-head.php snapshot sample.txt before.json
   ```
   Первая команда берёт по 50 адресов каждого вида из карты сайта, вторая записывает заголовки, описания и другие теги этих страниц. Запросы идут по одному раз в секунду — сайт этого не заметит.

## 2. Установка

1. «Плагины» → «Добавить новый» → «Загрузить плагин» → файл `indexpilot-1.0.0-rc1.zip` → «Установить» → «Активировать».
2. Пока включён AIOSEO (или модуль svl-seo), IndexPilot теги на сайт **не выводит** и показывает жёлтое уведомление — так дублей не будет. Это нормально: сначала переносим данные.

## 3. Импорт из AIOSEO

«IndexPilot» → «Импорт».

1. Сначала нажмите **«Показать, что будет перенесено»**. Ничего не записывается: вы увидите, сколько записей и полей перенесётся, и несколько примеров. Проверьте 2–3 примера глазами.
2. Затем **«Перенести»**. Импорт идёт пачками по 200 записей; если закрыть страницу или оборвётся связь, нажмите «Продолжить» — продолжит с того же места.
3. Поля, которые уже заполнены в IndexPilot, не трогаются (если не отметить «Заменять поля…»).
4. На kolodahearthstone.com так же перенесите **svl-seo**. Rank Math — запасной источник, его запускают последним и только если он был на сайте.
5. Данные AIOSEO импорт не меняет и не удаляет — к AIOSEO всегда можно вернуться.

То же из консоли сервера: `wp indexpilot import aioseo --dry-run` (показать), затем `wp indexpilot import aioseo`.

## 4. Отключение AIOSEO и svl-seo

1. «Плагины» → AIOSEO → «Деактивировать». **Не удаляйте** его: при удалении AIOSEO может стереть свои таблицы, а они нужны для отката.
2. На kolodahearthstone.com: в настройках плагина «KolodaHearthstone Locker» выключите SEO-модуль (svl-seo). Сам Locker не отключайте — он закрывает платный текст.
3. Жёлтое уведомление IndexPilot должно исчезнуть: теперь теги выводит он.

## 5. Что включить на боевом сайте

«IndexPilot» → «Настройки».

| Раздел | Что сделать |
|---|---|
| Поисковики → **IndexNow** | Включить. Яндекс и Bing будут узнавать о новых и изменённых страницах за минуты. Включать **только на боевом сайте**, не на тестовом |
| Поисковики → **Коды Google, Яндекса, Bing** | Вставить код подтверждения из кабинета (можно весь тег `<meta …>` целиком). Нужно, если кабинет подтверждён через тег AIOSEO: после его отключения подтверждение иначе пропадёт |
| Поисковики → **Роботы нейросетей** | По решению владельца: запрещает роботов, которые собирают тексты для обучения нейросетей. Поиск и ассистенты (ChatGPT, Perplexity, Claude) остаются открытыми |
| Поисковики → **Google-Extended** | Обычно не включать: закрывает не только обучение, но и ответы Gemini со ссылкой на сайт |
| Организация в разметке → **Название и логотип** | Название сайта как бренд («Manacost») и квадратный логотип не меньше 112 × 112. Это видят Google и ассистенты |
| Организация в разметке → **Страницы в соцсетях** | Адреса группы ВКонтакте, Telegram, YouTube через запятую |
| Колоды → **Номер текущего патча** и дата выхода | Вписать, например `37.0`. Обновлять с каждым патчем: тогда «Контент → После патча» покажет, что пора обновить |
| Колоды → **Версии колоды** | Включено: старые версии колоды указывают на новую, дублей в поиске нет |
| Переходы → **Площадки и блоки** | Проверить адреса Boosty, Hearthpulse, ВКонтакте, Telegram; вписать тексты блоков перехода. Без текстов блоки не выводятся — можно сделать и после переключения |
| Общие → **Удаление плагина** | Не включать на боевом сайте (см. раздел 9) |

## 6. Сброс кеша

После переключения и после каждого отката посетители и роботы должны получить новые страницы, иначе ещё сутки будут видеть старые теги.

1. **WP Rocket**: верхняя панель админки → «WP Rocket» → «Очистить кеш».
2. **Cloudflare**: панель Cloudflare → сайт → «Caching» → «Configuration» → «Purge Everything».
3. **Redis** (кеш объектов): «Настройки» → «Redis» → «Flush Cache», или на сервере `wp cache flush`.

Порядок именно такой: сначала сайт, потом Cloudflare.

## 7. Проверка и отправка карты сайта

1. Откройте `https://сайт/sitemap_index.xml` — должен открыться список файлов карты. Запасной адрес — `/sitemap.xml`.
2. Сохраните «снимок после» и сравните с «до»:
   ```
   php tools/compare-head.php snapshot sample.txt after.json
   php tools/compare-head.php diff before.json after.json
   ```
   В конце отчёта строка «Потеряли заголовок или описание: 0». Если не 0 — смотрите эти адреса выше в отчёте; при массовой потере — откат (раздел 8).
3. Search Console → «Файлы Sitemap» → добавить `sitemap_index.xml`. Яндекс Вебмастер → «Индексирование» → «Файлы Sitemap» → то же. Если там стоял адрес карты AIOSEO (`/sitemap.xml`), его можно оставить: этот адрес теперь отдаёт IndexPilot.
4. «Техника» → «Поисковики»: убедитесь, что файл ключа IndexNow открывается, и через день загляните в журнал отправок — там должны быть ответы «Принято».
5. На сервере можно проверить любую страницу: `wp indexpilot doctor` (сколько запросов к базе добавляет плагин).

## 8. Откат за 5 минут

Когда: на выборке пропали заголовки или описания, сайт выдаёт ошибки, или после переключения резко упала индексация.

1. «Плагины» → IndexPilot → «Деактивировать».
2. «Плагины» → AIOSEO → «Активировать». На kolodahearthstone.com — включить SEO-модуль в настройках Locker.
3. Сбросить кеш (раздел 6).
4. Проверить 2–3 страницы: в коде страницы снова теги AIOSEO.

Ничего не теряется: данные IndexPilot остаются в базе (поля `_indexpilot_*`, настройки, таблицы `indexpilot_*`), данные AIOSEO импорт не трогал. Повторная активация IndexPilot возвращает всё как было.

## 9. Обновление и удаление

- **Обновление**: загрузите новый архив поверх («Плагины» → «Добавить новый» → «Загрузить» → «Заменить текущую версию») или замените папку `wp-content/plugins/indexpilot`. Таблицы плагина обновятся сами при первом открытии сайта, настройки и поля записей сохраняются. После обновления — сброс кеша.
- **Удаление**: без галочки «Удаление плагина» в настройках удаление стирает только файлы — данные остаются в базе. С галочкой стираются все поля, настройки и таблицы плагина. На боевом сайте галочку не ставить.

## 10. Раз в неделю

- «Обзор»: список дел.
- «Аудит»: кнопка «Проверить сайт», затем дубли заголовков и пустые описания.
- «Ссылки»: кнопка «Обойти записи», затем записи без входящих ссылок.
- «После патча» — после выхода патча.
- Журнал ошибок PHP сервера: строк с `IndexPilot` быть не должно.
